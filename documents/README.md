# Documents du chatbot

Place ici les PDF que tu veux utiliser comme base de connaissances. Tu peux aussi
créer des sous-dossiers. Le programme conserve le nom relatif du fichier et le
numéro de page pour pouvoir fournir des sources dans les réponses.

Après avoir ajouté ou modifié un PDF, relance `python rag.py` pour mettre à jour
l'index local.

Les fichiers PDF sont ignorés par Git : ajoute tes documents localement après
avoir récupéré le projet depuis GitHub. Le dépôt contient ce guide, pas les PDF
de formation.
